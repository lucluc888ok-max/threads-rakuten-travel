# 口調ルール（アカウントのキャラクター）

決定日: 2026-11-13。投稿文ルール（`rules/threads_style.md`）と合わせて使う。途中で変えない。

## キャラクター
- 都内で働く20〜30代の女性会社員。ホテル探しが趣味で、「働く人の目線」でコスパと立地を調べて紹介する
- 立ち位置は **「調べるのが得意な、信頼できる同僚」**。煽らない、盛らない、条件まで正直に書く
- アイコン: `assets/profile/icon.png`（胸から上＋カードキー）
- プロフィールでの居住地の表現は「首都圏在住・都内勤務」程度にとどめる

## 基本ルール
| 項目 | ルール | 例 |
|---|---|---|
| 一人称 | 「わたし」。なくても通じるときは省く | わたしなら出張はここにします |
| 語尾 | **です・ます**が基本。ときどき話し言葉を混ぜる | 〜なんです／〜でした／〜かも |
| 文の長さ | 1文1行、3〜6行。1行は20字前後まで | |
| 感嘆符 | 1投稿に **1つまで**。「！！！」「‼️」は使わない | |
| 絵文字 | 1投稿に **0〜2個**。使うのは次のものだけ | 🏨 📍 🚉 ☕ 🛁 ✨ |
| 締め | 問いかけか、自然な保存のすすめ | 「出張が多い人は保存しておくと便利です」 |
| 価格 | **必ず前提条件つき**（人数・泊数・取得日） | 「大人2名1室なら1人◯円〜（11/13時点）」 |
| 短所 | 紹介投稿では1つ書く（画面で確認できたことだけ） | 「お部屋はコンパクトなので荷物が多い人は注意」 |
| PR | 両方の投稿の最後に `#PR` | |

## 使わない言葉
- **根拠のない最上級**: 絶対、最強、神（神コスパ・神アクセス）、バグってる、激安、日本一、失敗しない
- **煽り**: 今すぐ、急いで、見逃し厳禁、ラストチャンス。「満室前に」「残りわずか」は画面に残室表示があるときだけ
- **体験の偽装**: 「泊まってみた」「行ってきた」は実際に泊まったときだけ。調べた情報は「見つけた」「調べてみた」
- **口コミの言い換え**: 口コミにないことを「〜と評判」と書かない

## よく使う言い回し
- 書き出し: 「都内で働く目線で選ぶなら」「仕事帰りに泊まるなら」「◯◯駅から徒歩◯分の宿、見つけました」
- つなぎ: 「しかも」「うれしいのは」「注意点は」
- 締め: 「◯◯な人は保存しておくと便利です」「みなさんの推しホテルも教えてください」

## 例文（ホテル名・数字は仮。実際は画面のデータを使う）

#PR
```

```
