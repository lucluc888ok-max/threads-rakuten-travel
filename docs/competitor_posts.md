## zubora_sann の型（2投稿とも同じ構成）

**1投稿目（ホテル名を伏せる・リンクなし・写真1枚）**
1. 東京で見つけた{格安／穴場}ホテル。
2. {エリア}で泊まるのに、1万払う必要はありません。 ← 価格の基準を示して否定する
3. {駅}徒歩◯分＋アクセスの補足（3路線／豊洲・築地まで散歩圏）
4. 具体的な特典・設備（女子旅向けアメニティ無料／木桶味噌の和定食朝食）
5. もう1つの価値（24時間無料コーヒー／評価4.64）
6. 締めの一言（価格設定バグってます／教えたくない格安宿）
7. 「このホテルの名前は、」 ← 続きを読ませる引き
- 写真：外観または客室
- トピックタグ：「旅行」

**2投稿目（名前を明かす・リンクあり）**
1. 『ホテル名』
2. 価格「1泊◯円〜」
3. セール・お得情報（5%OFFの楽天スーパーSALE開催中／1日1組限定プラン）
4. 社会的証明「過去24時間で予約◯件」（楽天トラベルの画面の表示と思われる）
5. 浮いたお金の使い道（神楽坂グルメ／築地の海鮮丼） ← 周辺エリアの楽しみ
6. 「詳細はこちら👇」＋短縮リンク（a.r10.to）＋「pr」
- リンクのプレビューカード（楽天トラベルのホテル写真）が自動で付く

## 気づいたこと
- **伏せて引く構成が効いている可能性**：2件目にはホテル名を尋ねるコメントが付いている。
  2投稿目のいいねは1投稿目の約3割。
- **クーポンは主役ではない**：訴求の中心は「最安料金〜」と「1万円以下」。割引はセールの一言だけ。
  マニュアル（宿クーポンの割引額を訴求）とは違う。
- **低価格帯**：4,200円〜7,680円。報酬1%だと1件あたり数十円。表示回数で稼ぐ型と見られる。
- **煽り文句を使っていない**：「満室前に」などは使わず、落ち着いた断定調。
  ただし「神アクセス」「コスパ最強」「価格設定バグってます」など、根拠のない最上級表現はある。
- **PR表記が弱い**：「pr」が2投稿目の末尾に小さく付くだけで、1投稿目にはない。
  自分の運用では両方の投稿に #PR を入れる（ステマ規制）。
- **写真**：1投稿目にホテル写真を添付している。画像の出典・利用許諾は未確認。
  2投稿目のリンクカード（自動表示）なら問題になりにくい。

## 自分の型に取り入れる候補
- 型C「ホテル名を2投稿目で明かす」：1投稿目は特徴＋価格の基準＋「このホテルの名前は、」

## 5投稿（4アカウント）に共通すること
| 観点 | 傾向 |
|---|---|
| 1投稿目の主役 | **価格（1人◯円／1泊◯円〜）＋駅からの近さ**。5本すべて |
| クーポン・割引 | 主役にした投稿はゼロ。セールに一言触れたのは1本だけ |
| 1投稿目の長さ | 約60〜130字 |
| 感情語 | 神コスパ／最強／オシャ／コスパ最高（根拠のない最上級表現が多い） |
| 2投稿目 | **📍や🏨＋ホテル名（エリア）→ 事実の箇条書き（駅徒歩・開業年・レビュー点・設備）→ リンク → pr** |
| 写真 | 5本中4本が1投稿目に写真あり（楽天の施設画像と思われ、規約上は不可）。写真なしの #3 はいいねが少ない |
| PR表記 | 全員、2投稿目の末尾に小さく「pr」のみ |
| 価格の前提条件 | 書いている（#3・#5）／書いていない（#1・#2・#4）に分かれる |
| 切り口 | 格安（#1）、朝食（#2）、推し活・観光（#3）、歴史建築（#4）、オシャレ（#5） |

## 自分の型への反映（案）
1. **型D「価格＋立地」を主力候補にする**（競合の共通型）: 「1人◯円（2名1室）〜で泊まれる◯◯駅徒歩◯分のホテル」＋特徴1〜2個。
   価格は**必ず前提条件つき**。型A（割引訴求）は競合が少ないので、差別化として並行して試す。
2. **2投稿目を箇条書きにする**: ホテル名（区・最寄り駅）→ 事実3〜4点（駅徒歩、開業年・リニューアル年、楽天の評価と件数、設備）→ リンク → #PR。
3. **短所も1つ書く**（#3の「TVはないので注意」）。正直さが信頼につながる。根拠は画面で確認できたことだけ。
4. **写真の代わり**: 楽天の画像は使えない。都内勤務を活かして、**自分で撮った外観写真**を使えるか検討する
   （公道から撮った建物の外観は一般に問題になりにくいが、写り込む人などには注意。運用前に方針を決める）。
   当面は写真なしで始め、写真ありとの差を自分のデータで比べる。
5. **切り口のローテーション**: 価格／立地（駅）／朝食／推し活・遠征／歴史・新しさ、を順番に試す。
