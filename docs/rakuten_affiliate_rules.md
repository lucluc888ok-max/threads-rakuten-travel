## 1. Threads は使ってよい（C）
- 2023-07-13 に「認定SNS」に Threads が追加された。
- **新たに使う場合は、楽天アフィリエイトの「サイト情報」に最新のサイトURL（Threads アカウントのURL）を登録する。**

## 2. 画像（A・B）
- 楽天トラベルのページに載っている施設画像を**ダウンロードして SNS に投稿するのは禁止**。
- 楽天トラベル系APIから取得した画像も、**SNS への投稿は不可**（ブログ等では条件付きで可）。
- SNS に投稿する画像の部屋と、紹介する料金の部屋が違うのも禁止。
- → **自分で撮った写真以外は1投稿目に画像を付けない。** 2投稿目のリンクに自動で付くプレビューカードは、自分で画像を投稿していないので対象外と考えられる（ただし明記はなく、未確認）。

## 3. 金額（A・B）
- 「複数名で泊まった場合やその他条件が前提にも関わらず、**条件を省略して金額のみを記載**すること」は禁止。
  例: 2名1泊の料金なのに「1人◯円」と書く。
- → 金額を書くときは、**人数・泊数・プラン・利用条件額など画面に出ている前提条件を一緒に書く。**
  （`finalize` で、金額があるのに前提条件がない投稿をエラーにしている）
- 「その他ユーザーに誤解を与える様な紹介」も禁止。

## 4. キャンペーン・クーポン情報（D）
- 楽天内で**まだ公開されていない**キャンペーン情報（日程など）を事前に公開するのは禁止。
- **キャンペーンの「予想」の公開も禁止**（「個人の予想です」と書いても不可とされることがある）。
  → `docs/market_research_tokyo23.md` のスーパーSALE予想日程は**社内メモ用。投稿には使わない。**
- 過去の実績を書くのは問題ない。毎月固定の企画（5と0のつく日など）は事前に書いてよい。
- 対象者限定クーポン・エントリー者限定クーポンなど、**対象者限定で公開されている情報の共有は禁止**。
  → 「カード限定」「ボーナスプログラム」クーポンがこれに当たるかは**未確認**（楽天アフィリエイト事務局に確認するとよい）。
- 公開済みのクーポンは、獲得開始時期以降なら紹介してよい。

## 5. 報酬の対象（A）
- 対象: 国内宿泊など。**対象外: 日帰り・デイユース、深夜当日予約（ミッドナイトプラン）**、法人予約、福利厚生サイト経由。
- リンクのクリック後、**最初の予約だけ**が成果対象（2回目以降の予約は対象外）。
- **予約日から翌々月末日までに利用（チェックアウト）が完了した予約だけ**が成果対象。
  例: 11月の予約は1月末までのチェックアウトが対象。→ 先の時期の宿泊を勧めても報酬にならない。
- 楽天市場の「1商品1,000円上限」はトラベルには適用されない。

## 6. 違反時
- 修正依頼のメールが来る。悪質と判断されると予告なく利用停止もある（A）。報酬の支払い停止もあり得る（B）。

## マニュアル（裏ヌケ式）との関係
| マニュアルの記述 | 規約との関係 | 影響 |
|---|---|---|
| 投稿は文章＋アフィリエイトリンク。画像の添付は指示していない | 問題なし。ただし画像禁止の注意書きがない | 小（競合のように写真を付けると違反） |
| 「割引金額が大きい場合は具体的な金額をそのまま記載」 | 前提条件（人数・泊数）を書く指示がない | **中**（そのまま実行すると金額だけの表記になりやすい） |
| 「満室になる前に」（「実際の予約状況に照らして適切に」と注意書きあり） | 誤解を与える紹介の禁止 | 小 |
| セール・キャンペーン情報の活用（第4章） | 公式サイトで確認するよう書いている。事前公開・予想の禁止には触れていない | 小〜中 |
| 「別のホテルを予約しても報酬」（ついで買い） | クリック後の初回予約のみが対象、という条件の説明がない | 小（期待値の問題） |
| 報酬の対象期間（翌々月末まで）・対象外プラン | 記載なし | 中（遠い先の宿泊・デイユースを紹介すると報酬にならない） |
| Threads のサイトURL登録 | 記載なし | 中（登録漏れに注意） |
